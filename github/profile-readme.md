## / Proyecto destacado

### Pipeline de Reportes Aurora

Automatización de informes mensuales de seguridad para múltiples clientes.
- De días a **~15 minutos** end-to-end
- **7 etapas** declarativas: Extracción → Consolidación → Análisis → Narrativas IA → Gráficos → Ensamblado → Validación
- **122 tests** automatizados (60-90s)
- **7 clientes** en producción

[→ Ver showcase público](https://github.com/tu-usuario/pipeline-aurora-showcase)
