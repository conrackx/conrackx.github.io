# Content Strategy — marca-personal

## Pilares de contenido

| Pilar | Tono | Frecuencia objetivo |
|-------|------|---------------------|
| Data Engineering / Pipelines | Técnico, arquitectónico | 1 post cada 2 semanas |
| IA pragmática / LLM en producción | Crítico, orientado a riesgo | 1 post cada 2 semanas |
| Testing / Calidad | Práctico, transferible | 1 post cada 3 semanas |
| Marcas personales para técnicos | Reflexivo, personal | 1 post cada 4 semanas |

## Formatos

- **Blog post** (800-1500 palabras): análisis profundo, Mermaid cuando aplique, código mínimo necesario.
- **Thread Twitter/X** (8-12 tweets): extracto de blog, hook agresivo, un insight por tweet.
- **Carousel LinkedIn** (7-10 slides): hook → problema → solución → métricas → lección, máximo una idea por slide.
- **Case study** (2000+ palabras): proyecto completo, arquitectura, métricas, lecciones, repo link.

## Repurposing workflow

1 charla/blog post largo → 3 tweets aislados + 1 hilo + 1 carousel LinkedIn.
Mantener el mismo claim y métricas en todos los formatos. No reinventar el mensaje para cada canal; adaptar el vehículo.
